# Run the SeedCo app

This app now runs with MongoDB only.

## Run Locally

**Prerequisites:** Node.js and a running MongoDB instance.

1. Install dependencies:
   `npm install`
2. Configure MongoDB in your `.env` with `MONGODB_URI` and `MONGODB_DB`.
3. Build the app:
   `npm run build`
4. Start the server:
   `npm start`

## Development

To run the app in development mode with Vite middleware:

`npm run dev`
